# ProxyFlow 商店文案

以下是待维护者提交的文案，不表示条目已创建或审核通过。

**名称**：ProxyFlow

**简短说明**：独立管理 Chrome 代理：自定义入口、智能规则分流、多配置、在线规则导入与本地隐私控制。

## 详细说明

ProxyFlow 让你使用自己提供的 HTTP、HTTPS、SOCKS4 或 SOCKS5 代理入口，独立管理 Chrome 代理，无需开启 Windows 系统代理。你需要自行运行和维护代理服务；扩展不提供节点或 VPN 服务，不依赖某个代理客户端。

- 保存多个入口，自定义地址与端口，快速切换智能分流、全局代理、全局直连。
- 通过域名、后缀、关键词和有边界的 IPv4 字面地址规则选择直连、代理出口或拒绝。
- 从本地文件或可信 HTTPS 链接导入常见 Shadowrocket、Clash/Mihomo、v2rayNG/Xray 路由规则，先看兼容性报告和出口映射，再确认应用。不会运行文件里的节点或策略组。
- 管理规则订阅，支持手动或定时下载；下载只生成候选，不自动替换活动规则。
- 可选广告域名拦截、WebRTC 非代理 UDP 限制、请求诊断、配置备份恢复与明暗主题。
- 设置保存在本机，无账号、无遥测、不收集浏览历史、不向作者上传代理配置。站点访问和 WebRTC 权限由你按需授予。

代理失效时不自动切换直连；用户明确配置的 DIRECT 规则仍会直连。扩展仅控制它有权限管理的 Chrome 环境，不能接管其他应用或保证所有浏览器网络流量、DNS、WebRTC 与 QUIC 都经过代理。IPv4 CIDR 不查询域名 DNS。不支持认证代理、运行源节点协议、源策略组、外部 PAC 或完整广告过滤语法。HTTPS 下载来源必须可信，扩展不能可靠阻止 DNS 重绑定。
