# V1.0 权限审查

单一用途：让用户通过自己的标准代理入口控制 Chrome 代理路由，并管理相关规则与网络安全设置。不修改操作系统代理，不运行源配置中的节点协议。

| 权限                             | 必要性与用途                                  | 边界                                                                  |
| -------------------------------- | --------------------------------------------- | --------------------------------------------------------------------- |
| `proxy`                          | 通过官方 API 设置直连、固定代理或用户规则 PAC | 仅 Chrome regular scope；受企业策略/其他扩展控制权约束                |
| `storage`                        | 本地保存入口、规则、设置、订阅候选和状态      | 使用 local，不使用 sync；不上传                                       |
| `declarativeNetRequest`          | 规则 REJECT 与用户可选的广告域名拦截          | 不读取请求内容、浏览历史或统计计数                                    |
| `alarms`                         | 用户明确开启订阅周期后检查到期来源            | 无自动周期时清除调度；不自动应用候选                                  |
| 可选 `privacy`                   | 用户开启 WebRTC 非代理 UDP 限制               | 首次由用户授予；关闭清除本扩展覆盖；不承诺完全防漏                    |
| 可选 `http://*/*`、`https://*/*` | 诊断目标与 HTTPS 配置/订阅来源                | 未默认授予；每次按来源协议/主机申请，覆盖该主机全部路径和端口；可撤销 |

`optional_host_permissions` 的宽模式允许用户自行指定来源，不表示安装时获得全部站点权限。在线配置下载与订阅只接受 HTTPS，诊断可访问明确指定的 HTTP 或 HTTPS 目标。

没有 `management`、`history`、`tabs`、`webRequest`、内容脚本、遥测或外部脚本。仅调用无需 management 权限的 `getSelf` 识别自身安装渠道。MV3 CSP 限定本地脚本；无 eval、新 Function、远程代码或外部 PAC 执行。

远程输入校验：256 KiB、12 秒、UTF-8 严格解码、拒绝重定向和 HTML、无 Cookie/referrer、拒绝明显私网/本地字面地址、解析深度/规则数量/字段校验。域名 DNS 重绑定无法可靠检测，用户必须信任来源。备份允许 1 MiB 并单独校验格式、schema、危险键、字段和当前配置版本。

审核时请使用 [隐私政策](PRIVACY.md) 和 [实际验证边界](VERIFICATION.md)，不要将这些措施描述为完整网络流量接管或完全防止 IP 泄漏。
