# ProxyFlow 隐私政策（V1.0）

ProxyFlow 不要求注册账号，不采集浏览历史，不配置遥测，不向作者或自建云端上传设置。代理服务器、规则、主题、订阅 URL/参数、安全设置、转换候选/报告和错误状态保存在本机 `chrome.storage.local`，不使用同步存储，不在调试日志打印配置。广告功能不读取浏览历史，不记录请求或统计计数。

本地或在线导入的完整配置与附件只在页面内存处理，不保存节点内容，不访问文件引用的源 URL，不执行源脚本。用户应用后只保存转换后的规则。订阅需由用户自行添加 HTTPS 地址并授权站点：手动或明确选择 6/24 小时周期发起下载，转换报告/候选本地保存，完整源文本与远程节点密码不持久化；不递归请求源配置中的外部规则提供者。下载只生成候选，用户确认后替换规则。URL 可能包含令牌，它属于本地配置中的敏感数据，不公开分享。

在线配置、订阅与诊断请求遵循当前 Chrome 路由，不发送 Cookie、referrer，不跟随重定向。授权的网站与所选代理可看到请求、IP，以及下载 URL 中用户提供的参数，并可能自行记录。诊断取消响应内容读取，仅返回状态、耗时与检查结果。普通浏览行为仍遵循 Chrome 与代理服务自身的 Cookie、DNS 和网络处理，扩展不声称消除这些记录。网络失败不自动切换直连。

权限用途：

- `proxy`：控制有权管理的 Chrome regular scope 代理，不修改系统代理。
- `storage`：本地保存配置、候选与状态。
- `declarativeNetRequest`：用户路由 REJECT 与可选广告域名拦截。
- `alarms`：明确开启订阅周期后检查更新；无自动订阅则清除调度。
- 可选 HTTP/HTTPS 站点权限：用户指定的诊断目标与 HTTPS 配置/订阅来源。按协议/主机授权，覆盖该主机所有端口与路径，授权会保留至撤销；隐私页可撤销全部站点授权（包括订阅）。不预先授予所有网站访问。
- 可选 `privacy`：仅在用户开启 WebRTC 限制时申请，设置非代理 UDP 策略。关闭清除本扩展拥有的覆盖，权限本身仍可在 Chrome 中另行撤销。

不使用 content scripts、history、tabs 或 webRequest 权限，不执行远程代码或外部 PAC。订阅仅接受受限 HTTPS，校验体积和内容，拒绝明显本地字面地址；扩展不能可靠验证域名 DNS 重绑定，只授权可信来源。导出报告含规则域名、标签和固定出口 ID，分享前检查；报告不复制节点服务器、密码或源 URL 查询参数。

禁用/卸载释放本扩展的浏览器代理与 WebRTC 覆盖；卸载删除扩展本地数据。禁用/卸载释放行为仍需专门实机验收。DNS、WebRTC、QUIC、Chrome 内部网络、回环地址、已有连接与无痕环境可能存在控制限制。WebRTC 限制可能影响通话，不承诺完全防止 IP 泄漏，不控制其他程序或操作系统网络。

发布者仍需提供公开政策 URL、可联系的维护者与商店发布身份；此仓库不杜撰联系方式，也未完成 Chrome Web Store 审核。

在线配置导入只在用户点击并授权来源后下载，URL 和完整源文本仅在当前页面内存使用，不保存为订阅；只有明确应用的转换规则进入本地设置。256 KiB 上限、12 秒超时和严格 UTF-8 解码适用于在线配置/订阅。下载会向用户指定的来源发送请求，不向作者发送。

完整配置备份是用户主动导出的本地文件，包含代理入口与可能带令牌的订阅 URL，属于敏感信息；恢复前预览并确认替换，不自动授权来源。备份不会上传。删除导出的文件由用户自行处理。

扩展更新由 Chrome 按安装渠道处理。仅检查本扩展的安装信息，不枚举其他扩展，不要求 management 权限。商店自动检查与用户手动检查会联系 Chrome 的正常更新服务，携带扩展 ID/版本等更新信息，不携带 ProxyFlow 的代理地址或配置内容。当前 GitHub 解压副本不具备商店更新渠道。
