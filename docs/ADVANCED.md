# V0.3 高级功能与边界

## HTTPS 规则订阅

订阅格式沿用 [配置转换框架](IMPORT.md)：原生文本、纯域名、Shadowrocket、Clash/Mihomo、Xray，以及自动识别。仅提取规则，不运行节点、源策略组或源 DNS 设置。用出口映射 JSON 将源标签固定映射为 `PROXY`、`DIRECT`、`REJECT` 或 `PROXY:已有代理ID`；可先用本地导入界面检查格式与映射。

1. 在「订阅与规则更新」添加可信 HTTPS 地址、格式和映射。默认仅手动；保存手动订阅不会发起下载。
2. 点击「授权并下载更新」，授予该 HTTPS 主机的访问权限。6/24 小时更新在保存时申请相同权限。Chrome origin 权限按主机匹配，覆盖该协议主机的所有端口及路径，不能精确限制单个 URL。
3. 下载转换后查看候选规则和兼容性报告。有错误不产生新候选，显示失败报告供修复；不兼容项与语义变化必须主动确认。失败不更改活动路由，不静默切换直连；之前的候选如存在仍保留。
4. 点击「用候选替换全部规则」才提交配置。它替换整个规则列表，多个来源不会自动合并。配置版本、订阅参数或候选 token 改变后必须重新下载；确认勾选仅对当前候选生效。也可丢弃候选。

下载使用当前 Chrome 代理/规则。只允许 HTTPS，无 URL 账号密码或 fragment；不发送 Cookie、referrer，不跟随重定向，不执行下载内容。拒绝字面 IPv6、明显本地名称和常见私有/保留 IPv4，**无法可靠验证域名实际 DNS 解析或重绑定**。URL 查询令牌仅保存在本机配置中，谨慎分享；授权来源及所选代理可看到正常网络请求与 IP。完整远程配置、节点密码不持久化，仅存转换后的规则、报告、候选 token、时间、订阅参数摘要哈希与错误状态。导出/截图包含规则、标签或订阅 URL 时仍需检查隐私。

限制：最多 20 个订阅，每次下载 256 KiB，单候选记录 256 KiB，所有订阅状态缓存合计 1 MiB，规则沿用 500 条上限；下载超时 12 秒。HTML 响应、无效 UTF-8、超限、HTTP 错误和重定向均失败。源配置外部 rule-providers/RULE-SET 不递归下载，缺少附件或未知标签按兼容性报告处理。PAC、GFWList 与完整 Adblock 格式仍不支持。

调度使用一个 15 分钟 Chrome alarm，按照来源最近检查时间判断 6/24 小时周期，每轮最多处理 3 个最早到期来源。自动任务仍只产生候选；失败在下一个配置周期再试。关闭浏览器、休眠和 Chrome 调度会造成延迟，不是精确计时服务。无自动订阅则清除 alarm；删除订阅清理它的本地状态。撤销站点授权后该来源下载失败，不重新弹窗或改变路由。

## 广告域名拦截

默认关闭。内置 `doubleclick.net`、`googlesyndication.com`、`adservice.google.com` 三个示例，允许编辑最多 500 个唯一小写 ASCII 域名；不接受 URL、IP、`||domain^` 等 Adblock 语法。启用后通过 DNR 拦截该域名及子域的 HTTP/HTTPS 主页面与资源，三种代理模式均适用，优先级高于本扩展路由允许规则。关闭广告拦截仍保留用户编辑的域名列表。

这是小型域名列表功能，无下载广告库、元素隐藏、统计计数、浏览历史或请求日志。可能误拦整个网站；需要删除相关域名或关闭开关恢复访问。与其他扩展的拦截/允许冲突取决于 Chrome 行为，不能保证跨扩展优先级。

## 可选 WebRTC 控制

「隐私和安全」开启限制时单独申请 `privacy` 权限，将 `chrome.privacy.network.webRTCIPHandlingPolicy` 设为 `disable_non_proxied_udp`，scope 为 regular。拒绝授权或其他扩展/企业策略冲突时禁止启用并显示错误。界面展示读取到的实际值和控制级别。

关闭只清除本扩展拥有的策略覆盖，不写入默认值覆盖其他管理者；可选权限本身仍保留，可在 Chrome 扩展设置撤销。启用可能影响视频/语音通话或连接速度。限制非代理 UDP 不等于完全隐藏本地/公网 IP；DNS、QUIC/HTTP3、STUN 行为、Chrome 特殊请求、回环地址、已有连接与无痕配置仍需单独实测。扩展不改系统网络，不接管其他程序。

## 分层网络诊断

诊断不切换模式，不做端口扫描，不用一个端口开放结果宣称代理连接成功。它检查实际 Chrome 控制级别、PAC/固定代理与绕过列表、DNR 条件以及期望 WebRTC 策略是否生效。站点权限单独由用户授予；请求不发送 Cookie/referrer、不跟随重定向，12 秒超时。

| 代码                       | 含义                                                          |
| -------------------------- | ------------------------------------------------------------- |
| INVALID_URL                | 不是无凭据 HTTP/HTTPS URL                                     |
| CONTROL_CONFLICT           | 扩展未控制代理，包括权限冲突或配置尚未应用                    |
| CONFIG_DRIFT               | 实际代理/PAC/绕过项或 DNR 与本地配置不同                      |
| SECURITY_DRIFT             | 已选择 WebRTC 限制，但未观察到限制值                          |
| AD_BLOCKED / RULE_REJECTED | 广告域名规则或路由拒绝该目标，不发网络请求                    |
| HOST_PERMISSION            | 未授予测试网站权限                                            |
| HTTP_OK / HTTP_ERROR       | 已获得目标 HTTP 状态；成功不能独立证明出口 IP                 |
| PROXY_ERROR_OBSERVED       | 请求失败期间 Chrome 报告代理错误，但不能保证对应同一个请求    |
| TIMEOUT / NETWORK_ERROR    | 请求超时或失败，无法可靠区分代理、目标、TLS、DNS 与重定向原因 |

代理错误仅在本地保存安全错误码、fatal 和时间，不保留 Chrome 错误详情中的地址或敏感 URL。用客户端日志、不同目标与出口 IP 网站辅助核验。

## 升级与一致性

应用版本 0.3.0，存储 schema 保持 version 1，以附加默认字段兼容旧版：无订阅、广告关闭、WebRTC 遵循浏览器，不重置原代理和规则。新增必需 `alarms` 和可选 `privacy` 权限；实际 Chrome 升级授权、重新启用与策略表现仍需按 TESTING.md 验收。

Chrome proxy、DNR、privacy、storage 之间没有原子事务。失败会尝试恢复旧拦截与 WebRTC 设置，持久化失败尝试重新应用旧配置；仍可能有短暂不一致，恢复失败会报告错误，不能保证跨崩溃事务。若 privacy 权限在限制开启时被撤销，本地意图与实际设置可能不同，界面与诊断会要求检查；重新授权后保存，或关闭该限制再保存。订阅缓存保存和配置提交也不是同一事务，异常后应重新加载页面核验。
