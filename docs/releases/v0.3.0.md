# ProxyFlow v0.3.0 开发预览

ProxyFlow 使用 Chrome 官方代理 API，为 Chrome 提供独立代理管理，不修改 Windows 系统代理，不依赖特定客户端管理接口。

## 下载与安装

- `proxyflow-0.3.0.zip`：可加载的 Chrome 扩展安装包。
- `proxyflow-0.3.0-source.zip`：完整项目源码，包含测试、构建与文档。
- `SHA256SUMS`：上述两个附件的 SHA-256 校验值。

解压安装包，在 `chrome://extensions` 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。自行运行代理服务并填入实际地址、端口与 HTTP/HTTPS/SOCKS4/SOCKS5 协议。

## 本版功能

- 多代理入口管理，智能 PAC、全局代理、全局直连，本地存储与 Popup/Options 界面。
- Shadowrocket、Clash/Mihomo、v2rayNG/Xray 常见路由规则提取、出口映射与兼容性报告；不运行源节点协议或策略组。
- 经用户授权的 HTTPS 规则订阅、6/24 小时下载。下载仅生成候选，查看报告并确认后才替换全部活动规则；失败不自动切换直连。
- 默认关闭的广告域名 DNR 拦截，可编辑域名列表，适用于三种代理模式。
- 可选 WebRTC 非代理 UDP 限制，单独申请 privacy 权限。
- 实际代理、绕过项、DNR 与 WebRTC 状态检查，以及 HTTP、超时、权限冲突和代理错误分层诊断。

## 验证与已知限制

143 项自动化测试、ESLint、Prettier、TypeScript 与生产构建通过，发布流水线重新执行检查并校验 ZIP 完整性及权限。测试包括 Chrome API mock、受控网络响应、PAC VM 与 jsdom 交互。

当前开发环境的管理员策略禁止加载已解压扩展，实际 Chrome 代理请求、Windows 客户端、HTTPS 订阅和 WebRTC UDP 效果仍待实机验收。本版本未通过 Chrome Web Store 审核，不承诺完全防止 IP 泄漏。

不支持源节点/策略组运行、外部提供者递归下载、完整 Adblock/GFWList 语法、广告元素隐藏、认证代理或自动故障切换。DNS/QUIC、TUN、其他扩展与代理客户端自身路由可能影响实际出口。

升级保留 schema version 1 的原代理、规则和模式；新增 alarms 权限与可选 privacy 权限，新增订阅为空，广告与 WebRTC 限制默认关闭。安装/升级权限行为需真实浏览器验收。
