# ProxyFlow 1.0.0

V1.0 GitHub 正式软件发布，MIT 开源。Chrome Web Store 尚未提交/审核；上架后从商店安装才能获得标准 Chrome 自动更新。

## 新增

- 在线配置导入：输入可信 HTTPS 原始内容链接，按来源授权、受限下载，继续使用兼容性报告、出口映射和确认应用。不会执行节点协议，不自动替换路由，不自动建立订阅。
- 更新渠道识别：显示真实版本和开发/商店/管理员渠道；支持适用渠道的手动 Chrome 更新检查。开发 ZIP 不伪装成自动更新扩展。
- 本地配置备份、预览和确认恢复，便于从开发目录迁移到商店副本。站点权限不会随备份自动授予。
- 完整发布文档、隐私/权限说明、商店文案、真实页面截图及宣传素材。
- 后台只读下载不阻塞配置写入；保存后状态失败和持久化回滚失败提示更准确；修复测试依赖已知漏洞。

保留多标准代理入口、三种模式、PAC/DNR、常见格式规则转换、订阅候选、可选广告域名拦截与 WebRTC 风险控制。

## 安装与附件

下载 `proxyflow-1.0.0.zip`，解压；在 `chrome://extensions` 开启开发者模式，加载 **manifest.json 所在目录**。自行运行代理服务，填写其标准入口地址、端口和协议。升级前导出备份，使用同一开发目录替换文件并重新加载。

`-source.zip` 为源码，`-store-assets.zip` 为商店材料与两平台浏览器证据；`SHA256SUMS` 校验所有附件。不要将素材包当作扩展安装包。

## 验证与限制

174 项自动化测试、类型/格式/ESLint/构建通过，依赖审查当前为 0 个已知漏洞。发布流水线要求 Linux 与 Windows 的真实 Chrome for Testing 验收同一提交，通过后才公开附件；使用临时 HTTP 测试代理验证 fixed_servers、PAC、DNR、故障无自动直连、导入、权限拒绝、备份恢复与界面。报告见素材包。

尚未实测第三方代理客户端、HTTPS/SOCKS 入口网络、有有效证书 HTTPS 来源的成功下载与原生授权、WebRTC/STUN 效果、商店签名安装/升级。不能保证所有 Chrome 网络流量都经代理或完全防止 IP 泄漏。不支持认证代理、运行源策略组/节点、外部 PAC、完整 Adblock 和故障切换。详见仓库 `docs/VERIFICATION.md` 与 `docs/TESTING.md`。

普通 Windows/macOS 用户的自动更新请使用 Chrome Web Store；GitHub ZIP 无法自行在线替换解压目录。发布者需完成账号、条目、审核和发布，步骤见 `docs/STORE.md`、`docs/UPDATES.md`。
